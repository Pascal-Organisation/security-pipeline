# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting:
**Security** tab of this repository, then **Report a vulnerability**. Do not open a public issue
or pull request for a security problem.

Include the affected workflow or file, the version (tag), and steps to reproduce. You can expect a first
reply within a few days. Fixes are released as a new patch tag; credit is given if you want it.

## Supported versions

Only the latest `v3.x` tag is supported. Callers should pin that tag (or its commit SHA) and let
Renovate move the pin.
