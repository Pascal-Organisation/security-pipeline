# Security policy

## Reporting a vulnerability

Report privately: **Security** tab of this repository, then **Report a vulnerability**. Do not open a public
issue or pull request.

Include the affected workflow or file, the version (tag) and steps to reproduce. Expect a first reply within a
few days. Fixes ship as a new patch tag; credit on request.

## Supported versions

Only the latest `v3.x` tag. Pin it (or its commit SHA) and let Renovate move the pin.
